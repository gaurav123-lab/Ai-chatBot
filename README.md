# AI Chat Application

A modern AI-powered chatbot application built using React, Tailwind CSS, and Google Gemini API.  
The application provides a clean and interactive conversational interface with real-time AI responses and chat history management.

---

## Features

- Real-time AI responses using Gemini API
- Modern ChatGPT-style user interface
- Recent chat history sidebar
- Delete chat functionality
- Code block rendering support
- Responsive design
---
## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Vite

### API
- Google Gemini API

---


## Installation

### Clone Repository

```bash
git clone https://github.com/gaurav123-lab/Ai-chatBot.git
```

### Navigate to Project

```bash
cd Ai-chatBot
```

### Install Dependencies

```bash
npm install
```


## Environment Variables

Create a `.env` file in the root directory:

```env
VITE_API_KEY=YOUR_GEMINI_API_KEY
```

---

## Run Development Server

```bash
npm run dev
```

---

## Build for Production

```bash
npm run build
```

---

## API Security

API keys are managed using environment variables and excluded from version control using `.gitignore`.
